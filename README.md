# 💬 Projet : Application de messagerie sécurisée (Java)

## 📌 Description
Ce projet est une **application de messagerie sécurisée** en Java, permettant à plusieurs clients de communiquer via un serveur central tout en assurant la **confidentialité des messages** grâce aux chiffrements **RSA** et **AES**.

L’interface graphique utilise **Swing** avec **MigLayout** et **FlatLaf** pour une expérience utilisateur moderne.

## ⚙️ Technologies utilisées
- **Langage :** Java
- **Interface graphique :** Swing + MigLayout + FlatLaf
- **Sécurité :**
  - RSA pour l’échange de clés
  - AES pour la communication
- **Communication réseau :** Sockets TCP (serveur multithreadé)
- **Outils :** IntelliJ IDEA, GitHub

## 🚀 Prérequis
- Java JDK 11 ou supérieur
- IDE compatible Java (IntelliJ IDEA recommandé)
- Connexion Internet pour exécuter le serveur et les clients
