# 💬 Projet : Application de messagerie sécurisée (Java)

## 📌 Description
Ce projet consiste à développer une **application de messagerie sécurisée** en Java, permettant à plusieurs clients de communiquer via un serveur central tout en assurant la **confidentialité des messages** grâce au chiffrement **RSA + AES**.

L’interface graphique (Swing) offre une expérience utilisateur moderne grâce à **FlatLaf** et **MigLayout**.

---

## ⚙️ Technologies utilisées
- **Langage :** Java
- **Interface graphique :** Swing + MigLayout + FlatLaf
- **Sécurité :**
  - Chiffrement **RSA** pour l’échange de clés
  - Chiffrement **AES** pour la communication
- **Communication réseau :** Sockets TCP (serveur multithreadé)
- **Outils :** IntelliJ IDEA, GitHub
